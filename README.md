# ⛏️ Minecraft Style Python Code Editor (v0.1)

Pygame kullanılarak geliştirilmiş, Minecraft atmosferine ve renk paletine sahip minimalist Python kod editörü prototipi.

## 🌟 Özellikler
- 🎨 **Minecraft Cevher Renkleri:** Kod anahtar kelimeleri (`def`, `if`, `print`) elmas, zümrüt ve altın renkleriyle vurgulanır.
- 🔴 **Redstone Motoru:** Yazılan Python kodlarını arka planda çalıştırır.
- 💬 **Sohbet / Terminal Alanı:** Çıktıları Minecraft sohbet penceresi görünümünde sunar.
